# Showcase media

These assets show the actual current Phase 2A / 3D renderer, not the stable v0.2.0 binary. They are demonstration evidence, not an accepted v0.3.0 release.

| Asset | Content |
| --- | --- |
| [hero-city.webp](hero-city.webp) | Oblique schematic city, actual buildings/residents and City Pulse |
| [citizen-life.webp](citizen-life.webp) | Actual resident career, family and qualification evidence |

| [github-social-preview.png](github-social-preview.png) | 1280 × 640 repository social image, using an actual city crop |

The recording uses ordinary UI operations and real saved workspaces. No statistics, citizens, causal edges or scenario results were invented for the showcase. A separate resident inspection in the video is not a claim that the inspected resident caused a preceding metric change. All person/company names visible in the simulation are generated fictional entities.

Screenshots are WebP quality 88 at up to 1920 × 1280. The original PNGs, captures and capture helpers remain locally ignored. Historical design concepts are labeled as concepts under `docs/design`; they are not screenshots of implemented behavior.

Source code and third-party dependency licenses were not changed by media preparation. See the repository [LICENSE](../../LICENSE).
